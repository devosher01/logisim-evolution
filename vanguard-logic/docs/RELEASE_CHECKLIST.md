# Release Checklist

- [ ] Version updated according to Semantic Versioning.
- [ ] All quality gates pass on the release commit.
- [ ] Benchmarks show no unexplained regression.
- [ ] Document format migrations are tested.
- [ ] Security and dependency audits are clean or documented.
- [ ] Release notes include breaking changes and known limitations.
- [ ] Artifacts are reproducible and signed.
- [ ] Annotated tag `vanguard-v<version>` points to `main`.
- [ ] The release can be installed and upgraded on every supported platform.
